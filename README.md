# 📝 NoteVault

An AI-powered note-taking application built with **React** and **TypeScript** that helps users create, organize, and connect notes efficiently.

Inspired by modern knowledge management tools like Obsidian, NoteVault combines Markdown editing, AI-powered assistance, and bidirectional note linking to create a seamless note-taking experience.

## 🔗 Links

- **Live Demo:** https://react-notes-app-ivory.vercel.app/
- **GitHub:** https://github.com/Jaiv0ra/notes-app

---

## ✨ Features

- 🤖 AI-powered note summarization
- ✍️ AI-assisted Markdown formatting
- 📝 Markdown editor with live preview
- 🔍 Instant search
- 🏷️ Tag-based organization
- ⭐ Favorite notes
- 🔗 Obsidian-style note linking using `[[ ]]`
- ↔️ Automatic backlinks
- 📚 Connected knowledge graph
- 💾 Local storage persistence
- ✅ End-to-end tested core workflows

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Jaiv0ra/notes-app.git
```

Navigate to the project

```bash
cd notes-app
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
